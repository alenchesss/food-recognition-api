# Food Recognition API

Headless-приложение с REST API, которое позволяет загружать изображения продуктов и получать рецепты на основе распознанных ингредиентов.

## Функциональность
- Загрузка изображения с продуктами
- Определение ингредиентов с помощью ML-сервиса
- Подбор рецептов по найденным ингредиентам
- Возврат рецептов с недостающими ингредиентами

## Архитектура
Проект реализуется как микросервисное headless-приложение с REST API.

Сервисы:
- **api-service** — основной входной REST API и координация запросов
- **ml-service** — распознавание ингредиентов по изображению
- **recipe-service** — подбор рецептов по найденным ингредиентам
- **database** — хранение рецептов и служебных данных

## Стек
- Python
- FastAPI
- Docker / docker-compose

## Пример работы
1. Пользователь загружает изображение
2. ML-сервис определяет ингредиенты
3. Backend подбирает рецепты
4. API возвращает подходящие блюда
